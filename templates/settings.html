Garmin Connect

{% if garmin_lib %}De package garminconnect is geinstalleerd — echte sync mogelijk.{% else %}Voor echte Garmin-sync: python -m pip install garminconnect. Zonder die package werken CSV-import en demodata gewoon.{% endif %}

Eerste keer: klik op Verbinden met 2FA en voer de code uit je Garmin-app, sms of e-mail in. Je tokens worden daarna lokaal bewaard (data/garmin-tokens), zodat Nu syncen verder zonder 2FA werkt. Het wachtwoord wordt onversleuteld lokaal opgeslagen — alleen op je eigen pc gebruiken.

CSV-import (Garmin-export)

Geen zin in 2FA? Download je data op connect.garmin.com (⚙ → Gegevens exporteren) en import hier de CSV's (stappen, slaap, gewicht, HRV, ...). Kolommen worden automatisch herkend.

Gegevens exporteren

Download je opgeslagen data als bestand: metingen (CSV), maaltijden (CSV) of alles samen (JSON-backup, zonder wachtwoord en API-sleutel).

AI-advies

Kies waar de AI vandaan komt: lokaal via Ollama (privé) of via een OpenAI-compatibele API (OpenAI, OpenRouter, DeepSeek, Groq, ...). Via een API verlaten je gegevens je computer en rekent de aanbieder per gebruik.

{% if models %}Ollama is actief — kies het model dat het advies mag schrijven. De AI krijgt je metingen, maaltijden, activiteiten en de berekening van de regelengine. Voor de foto-analyse op de maaltijdenpagina heb je een lokaal vision-model nodig (bijv. ollama pull gemma3).{% else %}Geen Ollama gevonden op 127.0.0.1:11434. Installeer Ollama en draai bijv. ollama pull qwen3:8b, of gebruik hierboven een cloud-API. Zonder AI geeft de regelengine gewoon advies.{% endif %}

De AI is voorschrijvend beperkt: onderbouwing met fysiologische mechanismen en gevestigde richtlijnen, zonder verzonnen studies. De API-sleutel wordt onversleuteld lokaal bewaard en niet meegeexporteerd. Advies blijft educatief — geen medisch advies.
